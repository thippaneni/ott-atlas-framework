## Why

The HOOS product idea has been clarified: the first version should focus on home loan management and optimization, not broad origination, document AI, property intelligence, or marketplace workflows.

The current specs need a scope lock so future work sticks to the first five launch features and does not drift.

## What Changes

- Add an MVP scope document for HOOS.
- Lock the near-term product scope to five features: Loan Workspace, EMI Calculator, Part Payment Simulator, Balance Transfer Analyzer, and Loan Dashboard.
- Explicitly defer loan application intake/origination and other larger modules.
- Clarify that `HOOS-LOAN-001: Loan Application Intake` is not part of the immediate MVP implementation sequence.

## Capabilities

### New Capabilities

- `mvp-scope`: Defines the HOOS MVP scope guardrail and launch feature sequence.

### Modified Capabilities

None.

## Impact

- Product docs gain a clear MVP scope lock.
- Future OpenSpec changes should align with the first five launch features.
- No backend or frontend source code is changed.
