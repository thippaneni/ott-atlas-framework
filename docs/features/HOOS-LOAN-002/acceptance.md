# Acceptance Criteria

## Metadata

- Feature ID: HOOS-LOAN-002
- Artifact: Acceptance Criteria

## Criteria

- [ ] User can create a loan with valid required details.
- [ ] User cannot create a loan with missing or invalid required details.
- [ ] User can view active loans in Loan Workspace.
- [ ] User can view loan details.
- [ ] User can edit an active loan.
- [ ] User cannot edit an archived loan unless restored.
- [ ] User can archive a loan.
- [ ] Archived loans are hidden from the default active list.
- [ ] User can choose to view archived loans.
- [ ] Loan records contain fields needed by EMI, part payment, balance transfer, and dashboard features.
- [ ] Backend tasks target `hoos/HOOS-Backend`.
- [ ] Frontend tasks target `hoos/HOOS-Frontend`.
