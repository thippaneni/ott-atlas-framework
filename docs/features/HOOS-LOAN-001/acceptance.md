# Acceptance Criteria

## Metadata

- Feature ID: HOOS-LOAN-001
- Artifact: Acceptance Criteria

## Criteria

- [ ] Borrower can create a draft loan application with required minimum fields.
- [ ] Borrower receives a stable application ID after draft creation.
- [ ] Borrower can retrieve an existing draft application.
- [ ] Borrower can update draft applicant, property, loan intent, income, obligation, and consent fields.
- [ ] Borrower can add optional co-applicant basics.
- [ ] Borrower can review completed intake before submission.
- [ ] Borrower cannot submit incomplete intake.
- [ ] Borrower can submit complete intake and application status changes to Submitted.
- [ ] Submitted intake cannot be edited through draft update behavior.
- [ ] Backend tasks target `hoos/HOOS-Backend`.
- [ ] Frontend tasks target `hoos/HOOS-Frontend`.
