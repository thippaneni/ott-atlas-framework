## Product Direction

HOOS is a Home Ownership Operating System focused first on helping Indian home loan customers manage, understand, optimize, and save money on their home loans.

The first product version should avoid becoming a broad loan origination or property marketplace platform. The launch version should focus on high-value self-service workflows for existing or planned home loan owners.

## Current MVP Focus

For now, HOOS SHALL focus only on the following five launch features:

1. Loan Workspace
2. EMI Calculator
3. Part Payment Simulator
4. Balance Transfer Analyzer
5. Loan Dashboard

These five features are enough to produce a usable SaaS product quickly and solve real home loan problems.

## Build Order

### 1. Loan Workspace

Purpose: Let users create and manage one or more home loans.

Includes:

- Create loan
- Edit loan
- Archive loan
- Multiple loans support
- Loan amount
- Interest rate
- Floating/fixed type
- Tenure
- EMI
- Outstanding principal

### 2. EMI Calculator

Purpose: Let users calculate EMI from principal, rate, and tenure.

Includes:

- Monthly EMI
- Total interest
- Total payment
- Amortization summary

### 3. Part Payment Simulator

Purpose: Let users understand the impact of part payments.

Includes:

- Part payment amount
- Payment timing
- EMI same / tenure reduce option
- Tenure saved
- Interest saved
- New outstanding balance impact

### 4. Balance Transfer Analyzer

Purpose: Let users compare current loan with refinance options.

Includes:

- Current lender/rate/outstanding/tenure
- New lender/rate/fees
- EMI difference
- Interest savings
- Break-even analysis

### 5. Loan Dashboard

Purpose: Give users a simple operating view of their loan position.

Includes:

- Total outstanding
- Monthly EMI
- Interest saved
- Upcoming payments
- Loan summary widgets
- Basic cash flow indicators

## Explicitly Deferred

The following modules are important but SHALL NOT be implemented until the first five MVP features are specified, reviewed, and started:

- User registration, login, forgot password, subscription management
- Loan application intake/origination
- Disbursement management
- Repayment history import
- Property management
- Document intelligence
- AI financial advisor
- Notifications and automation
- Property intelligence
- Marketplace
- Social login, MFA, family accounts, role-based access
