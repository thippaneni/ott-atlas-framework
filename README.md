# OverTimeTechie Project Atlas Framework
OverTimeTechie Project Atlas is a reusable AI-Native Engineering Framework designed for Spec-Driven Software Development for Overtime Techie projects

Atlas provides:

- Engineering Standards
- AI Instructions
- Skills
- Patterns
- Templates
- Architecture
- Knowledge Base
- Coding Rules
- Checklists

Every AI coding assistant should read Atlas before generating code.

Philosophy:

Business Idea
↓

Specifications

↓

Architecture

↓

Implementation

↓

Testing

↓

Review

↓

Deployment

Atlas is framework-agnostic and can be used with:

- Codex
- ChatGPT
- Claude
- Gemini
- Cursor
- Windsurf

.atlas/
│
├── manifest.yaml        # Project identity & technology
├── index.yaml           # Atlas registry & dependency graph
├── capabilities.yaml    # AI agents and their responsibilities
├── contexts.yaml        # Context-loading profiles
├── principles.md        # Engineering philosophy
│
└── ...

| File                | Responsibility                                   |
| ------------------- | ------------------------------------------------ |
| `manifest.yaml`     | What is this project?                            |
| `index.yaml`        | What files exist and how are they related?       |
| `capabilities.yaml` | Who are the AI agents and what can they do?      |
| `contexts.yaml`     | Which context should be loaded for a given task? |
| `principles.md`     | What engineering values guide decisions?         |
