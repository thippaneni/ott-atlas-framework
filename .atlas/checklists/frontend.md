# Frontend Checklist

## Metadata

- Version: 0.1.0
- Status: Draft
- Layer: Checklists
- Depends on: skills/angular.md, instructions/frontend.md, standards/testing.md

## Purpose

Verify Angular frontend work against specifications, UX expectations, and API contracts.

## Checklist

- [ ] UI behavior traces to feature specification, UI design, or acceptance criteria.
- [ ] API calls follow documented contracts.
- [ ] Loading, empty, error, and success states are handled.
- [ ] Form validation is clear and consistent with backend validation where relevant.
- [ ] Accessibility expectations are considered.
- [ ] Responsive behavior is checked for target viewports.
- [ ] Critical user flows are tested or manually verified.
- [ ] Sensitive data is not exposed unnecessarily in the UI.

## Completion Criteria

The frontend change is ready when user-facing behavior is specified, verified, and aligned with API contracts.
