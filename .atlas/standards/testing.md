# Testing Standard

## Purpose

Ensure every implementation is verifiable.

## Standard

- Tests must validate documented behavior and acceptance criteria.
- Cover business rules, edge cases, and important failure paths.
- Keep tests deterministic, readable, and maintainable.
- Add or update tests when implementation behavior changes.

## Verification

- Acceptance criteria are covered.
- Critical paths have automated tests where practical.
- Test gaps are documented during review.
