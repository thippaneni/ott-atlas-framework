# Security Standard

## Purpose

Keep Atlas projects secure by default.

## Standard

- Never commit passwords, API keys, secrets, certificates, or sensitive credentials.
- Apply least privilege to users, services, and automation.
- Validate inputs and protect trust boundaries.
- Review authentication, authorization, and data exposure risks.
- Prefer secure defaults over optional hardening.

## Verification

- Secret exposure checks are performed.
- Security-sensitive changes receive focused review.
- Risks and mitigations are documented.
