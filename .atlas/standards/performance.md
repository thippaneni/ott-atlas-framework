# Performance Standard

## Purpose

Guide performance decisions with evidence and intent.

## Standard

- Prefer simple implementation until performance requirements are known.
- Measure before optimizing.
- Document performance-sensitive decisions and tradeoffs.
- Avoid changes that improve one path while silently harming critical workflows.

## Verification

- Performance requirements are documented where relevant.
- Measurements support optimization decisions.
- Regressions are considered during review.
