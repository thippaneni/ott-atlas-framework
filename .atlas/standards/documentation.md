# Documentation Standard

## Purpose

Ensure documentation precedes and supports implementation.

## Standard

- Document intent, scope, constraints, and acceptance criteria before implementation.
- Update documentation when behavior, architecture, or usage changes.
- Keep documentation concise, current, and linked to related specifications.
- Record architectural decisions and tradeoffs where they affect implementation.

## Verification

- New behavior has supporting documentation.
- Documentation and implementation do not contradict each other.
- References are readable and traceable.
