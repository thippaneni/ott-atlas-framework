# Frontend Instruction

## Metadata

- Version: 0.1.0
- Status: Draft
- Layer: Instructions
- Depends on: skills/angular.md, standards/testing.md, rules/api.yaml

## Purpose

Guide Angular frontend implementation.

## Scope

Use for UI features, components, routing, forms, state, API integration, and frontend tests.

## Instruction

- Start from UI design, feature specifications, and API contracts.
- Keep components focused and readable.
- Keep data access, mapping, and workflow orchestration out of purely presentational components.
- Mirror backend validation where the user needs immediate feedback.
- Preserve accessibility, responsive behavior, and predictable states.
- Add tests for important user flows and edge cases.

## Inputs

- Feature specification, UI design, API contract, standards, rules.

## Outputs

- Frontend implementation, tests, accessibility notes, UI behavior notes.

## Definition of Done

- UI behavior matches acceptance criteria.
- API interactions match documented contracts.
- Critical flows are verified.
